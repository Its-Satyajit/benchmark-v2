# Benchmark Suite Context

A multi-runtime, multi-stack benchmark suite evaluating desktop, CLI, web frontend, web backend, and meta-framework implementations against an identical complex game state replay stress test.

## Language

**Replay Log**:
A standardized serialized episode log (`.json`) containing initialization seed, card definitions, turn-by-turn actions, and state transitions.
_Avoid_: Dump, trace, recording

**Benchmark Runner**:
The harness responsible for orchestrating test execution, capturing process metrics, and aggregating results across targets.
_Avoid_: Test runner, evaluator, driver

**Target Application**:
A concrete implementation of the state replay engine in a specific tech stack (e.g. Native, Cross-Platform Desktop, CLI, Web Frontend, Web Backend, Metaframework).
_Avoid_: App variant, benchmark client

**State Simulation Engine**:
The core business logic within a Target Application that parses the Replay Log and steps through state validations and transitions.
_Avoid_: Game loop, simulator, replay parser

**Benchmark Metrics**:
Standardized measurements captured per run, including build duration (ms), binary / build output size (bytes/MB), cold startup time (ms), execution duration (ms), throughput (steps/sec), and peak memory (RSS/heap).
_Avoid_: Performance numbers, stats

**Build Artifact**:
The compiled standalone binary or packaged distribution output directory generated by building a Target Application in release/production mode.
_Avoid_: Dist folder, executable

**Benchmark Report**:
The aggregated multi-format output (terminal summary table, `results.json`, and Markdown/HTML comparison matrix) generated by the Benchmark Runner after testing target applications.
_Avoid_: Output log, test summary

**Saturation Stress Test**:
A high-intensity multi-core benchmark workload that runs concurrent batches and memory-intensive state snapshot trees to push CPU throughput, memory heap, and event loops to their physical limits.
_Avoid_: Load test, hammer test, smoke test

**Snapshot Tree**:
An in-memory historical tree of full player boards and deck states retained across turns to induce maximum memory allocator and garbage collection pressure.
_Avoid_: State history, memory dump
